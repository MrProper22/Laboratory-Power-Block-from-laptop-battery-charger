# Laboratory-Power-Block-from-laptop-battery-charger

Here is principal scheme of the device. In general it just converts DC circuit from laptop charger. The core of the device was DC-DC converter XL4016, potentiometrs allows to change the circuit and voltage. To check the numbers and see parameters I connected volt-ampermeter.
